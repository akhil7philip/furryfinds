# Furry Finds

https://furryfinds.club

Expert reviews, comparisons, and buying guides to help you make informed purchasing decisions.

**Stack:** Next.js 15 + TypeScript + Tailwind CSS + Markdown/MDX  
**Hosting:** Vercel | **Publishing:** GitHub API via Kimi Claw

## Environment Variables

Copy `.env.example` to `.env` and fill in your GitHub token.

## Publishing

Articles are published to `content/posts/` via `scripts/publish-post.js` (Kimi Claw pipeline).
